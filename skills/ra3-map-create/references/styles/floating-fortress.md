# 浮岛要塞：海上钢铁平台

本页用于日本科技风格的巨型海上要塞。它的结构是人工甲板、侧壁、模块通道和设施院落；先制作这些结构，再做装饰。不能把它当成刷了钢铁贴图的普通自然岛。

## 分层设计：从海底到甲板

1. **海面与海底**：水域要围绕平台并保持船只通道。海底可以有独立残骸，但不承担平台顶层道路功能。
2. **平台主体**：决定每片甲板的边界和高度。外缘应是人工直线、折角、规则突出部和少数有功能的圆端；不要用自然沙滩作为主体过渡。
3. **平台侧壁**：沿甲板边缘拼侧壁/边缘模型，使顶沿与甲板相接、下沿向海面延伸。高处俯看和低处侧看都要检查；俯视贴上去不等于底部已经接好。
4. **甲板底纹**：使用同一族的 `SteelDeck01`、`SteelDeck02`、`SteelDeck03`、`SteelDeck04` 候选，划出走行面、设施基座、服务区。`Asphalt01`、`Asphalt04`、`Asphalt05` 可用于相容的车行/作业面，不要把全部甲板混成花纹拼布。
5. **道路与边带**：路缘/细边线组织通道，路口连接院落入口；白线、条纹、格栅具有功能，不能随机铺满。
6. **院落设施**：建筑、通风设备、货箱、吊机各有作业空间；人工植被区最后加入，不代替工业设施。

地表统计里可能包含甲板下方的 `Dirt_Yucatan03/04/05`。这不是“露天钢铁平台应该刷热带泥地”的证据。先看该位置在画面中是否暴露。

## 通道、转角与平台层高

先读 [道路制作](../road-construction.md)，对照 [m064平台端头](../../assets/roads/m064-focus-crop.jpg)。IF是StreetSegment车行面，FI_EdgePiece是平台结构，IslandFortressSidewalk/Trim是Road细部，钢铁底材另铺；本集合没有FI_STREETSEGMENT。

- **普通车行段**：先放两段直线，验证连接后再补转角。m064 的连续圆弯车道绕过围合区，转弯由同族端点接合；不要拼一串很短的道路让道路呈蛇形。
- **街道模型候选**：`IF_StreetSegment01`、`02`、`03`、`07`、`08`、`12` 在多个案例出现；`01` 的部分邻接样本中心差约 120 世界单位，不能因此把所有 IF 道路步长定为 120。IF01实测120×92.444、前进轴候选X约120；IF07实测30×92.444、候选X约30，最长Y是横向宽度；IF12实测49.749×100.050且原点偏心、连续轴未确认。按每型号真实端点接合，街段的模型角度不一定就是道路行进方向。m064 #1027 IF12的Z=1/align缺省与SteelDeck/Asphalt底材是该位置记录，不能推广给全族。
- **道路工具候选**：`IslandFortressSidewalk01/02/03`、`IslandFortressTrim01`、`HavanaWhiteLine01`、`HawaiiCrosswalk01` 是路缘/线条/过街标记，不能代替整幅车行道。正式路口才放过街标记。
- **不同高度**：院落顶面、路面和平台边缘分别取高度。m064 的下凹院落有独立侧壁和出入口，不能用一块平铺地表模拟真实落差。需要人员/车辆可通行时用真正坡道或相容连接模型；台阶只用于视觉/步行空间，不宣称一定能通过车辆。
- **接缝小样**：先做一个直边、一个外角、一个内角、一个高度连接点。检查甲板面、顶沿、侧壁、底部、通路五件事都成立，再放大规模。

## 三类功能区的简明配方

| 功能区 | 制作顺序 | 最后检查 |
|---|---|---|
| 技术设施院落 | 甲板矩形 → 设施入口 → 通道 → 路缘 → 设备 → 围栏开口 → 灯 | 入口畅通、基座同高、设备不穿模 |
| 货运端头 | 水侧边缘 → 吊机 → 空作业面 → 货箱区 → 围栏/入口 → 服务车道 | 吊臂能覆盖装卸面，货箱和路分开，船位有水深 |
| 人工绿化庭院 | 甲板 → 矮挡墙/槽边 → 少量土/草底 → 成组植物 → 硬质步行入口 | 绿地有明确人工容器，植物不从裸钢板随机长出 |

## 纹理与视觉故障检查

先铺大块甲板底纹，再按功能分设备基座和道路；结构接缝使用相容的模型边/路缘，不用一圈自然羽化草把接缝藏住。边缘工具是否能正确生成过渡，取决于本编辑器当前实现和材料数据；先做小块、保存、重新打开、俯视与低角度侧看。若出现异常白面、锯齿、旧贴图消失，记为解析/绘制问题，不记录成规范，也不以更多装饰遮盖后宣布完成。

完成一个平台区时应能用一句话解释：它为什么有这个边界、从哪里进入、什么面供通行、什么面供作业、侧壁如何接海面。解释不出来的设备先不要放。
