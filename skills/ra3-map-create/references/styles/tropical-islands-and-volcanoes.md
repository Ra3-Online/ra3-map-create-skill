# 热带群岛、复活节岛与火山

同属热带，不代表都使用同一套建筑和海岸。先确定是礁湖小岛、岩岸高地、复活节岛村落，还是火山熔岩地带；生活聚落只能建在能解释其道路、地面与水岸的稳定区域。

## 常用对象：自然地貌

先用真实地形做落差，再用崖体覆盖可见岩面。每个模型的长度、凸凹端、根部和局部朝向分别核查，不按 ID 结尾猜几何。

| 对象 | 用途与位置 | 朝向 / 邻接 | 错误摆法 |
|---|---|---|---|
| `EI_CliffWall01`、`EI_CliffWall02` | 常见灰黑岩崖候选 | 岩面朝低处，草顶贴高地，邻件顶沿连续 | 将岩墙平铺在草地中，或反向露背面 |
| `EI_CliffWall03`、`EI_CliffWall04`、`EI_CliffWall05` | 不同长度/转折候选 | 预览真实端头，按目标轮廓选件 | 所有弯角仅旋转同一直件，接缝悬空 |
| `EI_CliffWall06`、`EI_CliffWall07`、`EI_CliffWall08`、`EI_CliffWall09`、`EI_CliffWall010` | 台地与海岸补件 | 区分 GRID 和非 GRID 版本；不能当同一原点/高度模型 | 全部中心等距，或两个不同版本共用固定 Z |
| `EI_CliffWall06_GRID` 等 GRID 型号 | u068/69 的规则台地候选 | 观察直段曾有约 120 世界单位的中心相邻样本，但仍须验证本型号端点 | 以一个样本把所有崖件定为 120 间距 |

## 四类地表的层次

| 地表层 | 候选 | 画法与位置 |
|---|---|---|
| 火山裸岩 | `Cliff_Easter01/02/03` | 陡坡/火山体。平地不应刷成连续竖岩纹；按坡度和岩体解释 |
| 冷却地/土路 | `Dirt_Easter01/02/05/06/07/09`、`Dirt_CapeCod02/04` | 谷地通路、村前磨损、岩外缘；选少数冷暖相容材料，不全目录刷一遍 |

| 岸/水下 | 案例适配的沙、`Reef_Yucatan02` | 岸沿湿沙/裸岩到浅水，再到深水；不要将礁纹刷到高地住宅场 |

土路候选 `EasterIslandRoad01/02`；两者先验证宽度/端点。宽路连接村节点和坡口，细路接具体屋门/景观，别穿陡壁。路径可以绕过一块岩体，但不能每一段都折弯。自然过渡以较大的草土形状和局部混合为主，城市硬场和码头边保持规则边。

## 一个有层次的岛屿：执行与验收

1. 定主岛与航道，再画高火山/岩脊、冷却台地、低谷、坡口、沙岸五层；不要只把周边压低而岛内全部同高。
2. 决定是否有活熔岩。没有用户要求则不默认大量发光流。
3. 主路放在冷却低谷，把上层小村用真正坡口连接。
4. 村屋、菜园/绳篱和主题景观有节点关系，原比例不互压。
5. 海岸决定哪些为自然岩岸，哪些为人工小码头；换边方式在明确端头，不做混乱锯齿。
6. 分层刷岩、土、草、沙，最后做局部边缘细化。贴图齿边或旧材料被遮住需要检查编辑器/数据，不承诺自动边缘按钮能解决所有情况。
7. 检查全图轮廓、山体侧面、坡口、村门、岸和码头。删除无法解释用途/不在当前目录的白块、光柱、未知残缺模型，再扩展。

天气、雾、滤镜和水色需要另按用户意图设置。上述诊断图曾关闭雾/Bloom，不能把诊断光照当作游戏最终效果；新增效果必须在目标游戏里核查，不用遮挡来掩盖接缝。
