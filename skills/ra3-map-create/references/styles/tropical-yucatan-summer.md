# 尤卡坦夏季：村镇、度假设施与岩岸

这是温暖尤卡坦主题的制作页。按“地区 + 季节 → 场景 → 设施”选择配方；不能把椰树、旅馆、草屋和港口设备全部混到同一个院子里。热带火山与复活节岛另读 [热带群岛与火山](tropical-islands-and-volcanoes.md)。

## 按三级分类选择组合

| 二级 → 三级 | 主体 | 配套 | 不应出现的组合 |
|---|---|---|---|
| 村镇 → 草屋住宅小组 | 原比例草屋、短门前路、小共享庭院 | 竹篱、少量树、灌木、伞桌/生活物件 | 草屋和金属集装箱码头无缝混成住宅院子 |
| 村镇 → 医院/车库 | 公共服务建筑、硬质前场、可驶入通路 | 停車/候车边、少量灯与绿化 | 医院没有出入口，救护/车辆只能翻越崖壁 |
| 度假区 → 旅馆前场 | 旅馆主入口、步行广场 | 白长椅、花坛、伞桌、侧向停车 | 用车辆和竹篱堵住步行广场 |
| 度假区 → 海滩 | 沙滩、通海短路 | 遮阳伞、岸边植物、少量停靠小船 | 伞桌漂在水上，或所有沙滩上排一条高崖 |
| 自然野地 → 岩岸 | 岩壁、草顶、裸露岩面、沙/浅水 | 主树、小树、地被、岩石成组 | 树平均铺满坡道，海崖面刷城市地砖 |
| 自然野地 → 上层平台 | 有形状的高地、能上去的坡口 | 低密度植被/岩石，沿路停留点 | 高地只是一块大平板，没有谷地、肩部和坡口 |

## 悬崖位置、角度与接缝

`YU_CliffWall04/05/06` 和 `YU_SeaCliffWall01/02/03/04/05/06` 在上述案例多见。每个型号单独预览，不能把“海崖”当作固定高度的一圈城墙。

1. 先有真实地形落差，再以模型填岩壁可见面：草顶沿高处，岩面朝低处，海崖接水岸。
2. 每段的直端、凸角、凹角形态先确认；邻件顶沿连续，底部接低地/水边，主体轻微相交只用于隐藏接缝，不能将整件互相压进。
3. 模型朝向按崖面和几何接口决定；不要因为民房主轴是奇数 45°，就把自然岸线强制四方向。
4. u015 的部分 `YU_SeaCliffWall04` 样本是地形相对 Z=55；同图其他段 Z=0。数值是特定岸段观察，不是所有海崖“必须加 55”的公式。
5. 检查直段、转角、坡口三类接口。坡口需要留无崖墙的通路，不能给一条贴图路穿过岩壁后算连接成功。

## 贴图与路网：从功能到边缘

| 位置 | 候选材料 | 关系与画法 |
|---|---|---|
| 村落/林地草底 | `Grass_Yucatan02/05/07/09` | 大块主草色，少量相容干湿变化；树根与裸土有解释，避免棋盘混色 |
| 路口、小院、磨损地 | `Dirt_Yucatan03/06`、`Gravel_Yucatan01` | 门前/人走的位置有土或碎石；不要随机在草坪刷无目的小斑 |
| 岩壁/坡脚 | `Rock_Yucatan01/03/04` | 接岩体、坡脚与土，不能把整个平地刷成竖向岩纹 |
| 旅馆前场 | `Pavement_Yucatan01` 或相容铺装 | 规则硬边、入口轴线，与车行面/停车线分别组织 |
| 沙滩/浅水 | 适配样例的沙、`Reef_Yucatan01/02` 候选 | 沙边沿岸，礁纹位于水下；统计频率不能决定陆上铺礁纹 |

看 [u015村路](../../assets/roads/u015-focus-crop.jpg) 并读 [道路制作](../road-construction.md)：该场景用YucatanDirtRoad01/Footpath01/Road01/02等两点Road连接住屋与坡口，不要求先铺城市StreetSegment。土路、步道和装饰边线各有用途，材质表面不能替代真实通行。

先刷大形：草地、裸土、岩壁、沙岸、硬场。再画真正连接门口的道路；最后局部细化边缘。道路候选为 `YucatanDirtRoad01`、`YucatanFootpath01`、`YucatanRoad01/02`、`YucatanSidewalk01`，各有功能；细园路不代替汽车道路。道路应经过坡口，主要直段长一些，只在地形/目的地需要时转弯，不能用很多短弯追着每一棵树绕。

**纹理交界检查**：先做小块硬场和一段自然边，使用当前可用的边缘细化工具后，检查 2D、3D、保存重开。自然边可以有不规则大形；城市硬地边应明确，不应每格出三角齿。若齿形持续、旧材料被隐藏或平滑高度后纹理突然改变，记录为数据/渲染问题；不要声称“多按几次自动边缘一定解决”，也不要靠植被遮完当成通过。

## 低能力模型可以照做的村落流程

1. 画一块有坡口的上层平台和能到达它的主路。
2. 选 3～5 栋原比例候选草屋，围绕小共享场地放，门朝场地。
3. 每栋接一条很短的门前路，共享场地接主路。先检查可达，再放院界。
4. 放少量竹篱，留开口；一组高树在后侧，灌木在侧边；前场留空。
5. 如果有伞桌/长椅，只选一个生活节点，检查座向和净空。
6. 最后刷脚下磨损、坡脚岩/土和草地变化，局部边缘细化。
7. 从全图、村落、门前、崖底四个尺度截图；门被挡、房屋重叠、模型悬空或边缘锯齿，先修再扩展下一组。
