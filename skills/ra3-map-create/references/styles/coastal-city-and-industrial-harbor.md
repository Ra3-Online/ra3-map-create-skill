# 暖季滨海城市、休闲岸区与工业港口

本页按功能组织，不按战役阵营强定地域。夏威夷、混合海滨度假城、工业码头、体育公园各有不同的建筑与道路组合。确定风格时先选一支，不把它们全部塞进同一街区。

## 三类城市空间怎么搭

### 海滨酒店与步行广场

u059 近景说明的是“建筑 → 步行广场 → 海景”的关系：旅馆入口在广场一侧，停车位位于靠道路的一侧，花坛、桌椅、伞和长椅占广场的停留节点；木码头通水，少量船停在码头边。广场保留连续走行面，花坛不是每个空格一个圆圈。

候选旅馆分别为 `GI_Hotel_01`、`GI_Hotel_02`、`YU_Hotel01`、`YU_Hotel02`、`YU_Hotel04`；住宅候选 `GI_Apartment_01/02/03`。每栋原比例、入口对前场、屋檐不重叠；不要为了变高低缩放建筑。u059 的 `GI_Lighthouse_01` 为岸边地标候选，须在可解释的航道/岸点，不每个酒店旁都放一个。

### 夏威夷小院与体育空间

m066 的小院与公共绿带以窄人行带、低围界、树和街灯连接，停车块靠道路，体育场地有独立边界。资产混用 `HA_Building16_02` 等亚洲形式，不等于把城市文化归为日本。`CA_Hotel_01` 等较大建筑在适合的公共地块；不要在每个住宅院里混入旅馆。

### 工业货运港

先岸边卸货面，后吊机、货箱区、车行道和陆侧仓库。仓库门前留转向与装卸空间，货箱不穿进仓库、路灯不挡吊臂。桥连码头时桥头、护岸顶沿、路面同高。工业港与游乐/酒店区可邻接，但要用道路、绿带或硬质边界明确分开。

边缘细化前先判断两边功能：自然草土允许有大形自然变化；酒店铺装和码头边沿应规则。保存重开、近景和俯视复查三角齿/旧纹理丢失。当前工具存在问题时标出未通过，不能把大量灌木盖住当作已修好。

## 最小街区配方

1. 一条主路与一片滨水步道先连接，确定岸边为自然还是人工。
2. 在陆侧放原比例旅馆/住宅，入口接步行前场；侧面放可驶入的小停车区。
3. 两三个休闲节点选择长椅、垃圾桶、伞桌/花坛，不让每节点都用全部物件。
4. 绿化填树下、墙边和有功能的空地，主路/前门留净空。
5. 货运港若需要，放在独立岸段，以硬场/道路与休闲区区分，再放吊机、箱区、仓库、车。
6. 灯面照路、椅面看景、箱门可接近、船停水里。任何一条不成立，先修这个节点再复制下一块。
