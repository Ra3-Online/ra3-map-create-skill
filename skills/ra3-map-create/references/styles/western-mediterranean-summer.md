# 地中海暖季：希腊小城、干燥丘陵与工业港

## 范围与来源

原版战役来源 m079 Mykonos 的全图 12 分区已实际查看，另放大住宅/餐饮院落近景。它是暖季希腊白墙、亮色屋顶、干燥山地与紧凑小城的明确来源。u048/u049/u050 是起义合集社区整理的官方来源挑战场景补充，已看全分区；它们给出海崖、山顶小城与土路关系。u032/u033、u066/u067 可作温暖工业沿岸的功能对照，但没有独立地理证据把它们全部命名为希腊。国家未知就标“暖色工业海岸”，不能强配国家。

## 城市 → 白墙居住街块 → 民房、公共节点与庭院

观察：m079 住宅用少量相容型号组成规则街排；有些地块是单屋加庭院，有些是长条集合住宅；餐馆、教堂与小广场是节点。草地/花圃只在城市特定种植区，城外是干燥褐色自然地表和连续土路。不能因为城内绿色庭院就把整片希腊野山刷满温湿草地。

| 功能组 | 精确候选 ID | 用法与邻接 | 不适合 |
|---|---|---|---|
| 住宅 | `MY_House_01`、`MY_House_02`、`MY_House_03`、`MY_House_04`、`MY_Apartment01` | 先辨别真实正面；门接街或小院路，原尺寸摆放；同街块限定相容型号，屋顶与白墙保持地区感 | 缩放互穿造城市墙、屋底跨崖、每间小屋都配酒店广场 |
| 旅馆 | `MY_Hotel_01` | 大一点前场和停泊位，临主街/公共节点；海沿旅馆与步道配合 | 无路到达的山顶、普通窄巷硬塞大底板 |
| 餐馆 | `MY_Restaurant_01`、`MY_Restaurant_02`、`MY_Restaurant_03`、`MY_Restaurant_04` | 在入口一側留餐饮前场，配桌、伞、少量植物；户外家具的使用先看模型已有家具，避免重复叠加 | 铁路/工业装卸场摆露台、桌椅把门堵满 |
| 教堂 | `MY_Church_01`、`MY_Church_02` | 识别轮廓，接主步道与小前场；低围界/绿化在边缘；多教堂仅当城镇尺度和设定合理 | 当普通住宅等距重复、树挡住主入口和塔体 |
| 历史/纪念节点 | `MY_Statue_01`、`MY_Statue_02`、`MY_Statue01`、`MY_Windmill_01`、`MY_Pillar_01` | 主题需要才选；柱/废墟可在明确历史地块，风车与坡顶开阔关系先确认 | 把完整白墙住宅区混成随机遗迹堆，全部雕塑聚集一个广场 |

三级庭院模板：前部硬地入口 → 建筑 → 侧后种植区；必要时用低墙分产权。餐饮前院是活动硬地，居民后院是植物/生活，教堂前院是到达/静态景观。每类家具和地表随功能变，不复制同一“树＋桌＋伞”到每栋。

## 城市 → 围界、家具与绿化

| 类型 | 候选 | 用法 |
|---|---|---|

| 路灯 | `MY_Light01` | 沿街与公共步道；检查灯头/光锥实际服务面，不以对象 angle 单独判断 |
| 植物 | `MY_Plant05`、`CS_Palm01`、`CS_Palm02`、`CC_Grass07` | 城市绿化受维护，可在庭院成小组；城外稀疏植被依坡脚、石缝与土壤变化，不均匀撒所有花草 |

道路型号小样见 [道路制作](../road-construction.md)：m079观测170个MY_StreetSegment普通Object全Z=1，MykonosSidewalk/Trim等Road另作边带；这个偏移只适用于该图记录，不推广到AM/ST，也不据名字替未知接口认证。

道路与民房主方向按用户指定的 45° 奇数倍世界轴为主；庭院短路与岸线根据形态缓慢转折。围墙沿真实地块边界接段，不用缩放或叠墙遮缝；转角要选已预览的配套段或正确端部，低墙不能强充悬崖面。

## 自然地形 → 海崖、坡脚、野地与土路

希腊海崖看浅灰/浅米岩壁与干地顶部的相容色，不把俄国雪岩或深色火山熔岩当泛用悬崖。具体 `MY_CliffWall...` 系列在观测目录可查，每段高度、长度、弧形与前后面仍须模型预览。使用流程：台地边线 → 同族墙面 → 相邻端部 → 角部 → 顶部收边 → 坡脚岩块与小植被。留通路位置后再接墙，不能用连续岩面堵住山路。

墙面朝低处，最高边对应台地顶；若天然崖前方是水，岩壁下部与水/岸石衔接。局部伸出的岩块可打破轮廓，但数量低于连续岩壁主结构。每块物体不能为了“自然”随机转一圈；相邻墙面角度变化服务于边线，几何端部相接。

土路主干连实际村镇/入口/公共节点，少数支路接小地块；弯道大而少，沿高差边走，坡道处缓慢改变高程；不要重复 3–4 个短折角绕每一栋屋。地表细化只用于自然地面之间，保护城市硬边。

候选材质可包含地表不可见底层；当前目录可用性与截图同时决定。主区域边界优先符合道路、庭院、台地，随后只在需要的自然交界作局部细化。45° 斜边发现锯齿时，不全图喷第二纹理以掩盖；做短样板，比较硬边/局部细化，检查地表与当前渲染是否一致。建筑底板是模型部分，不能以刷另一层贴图声称已经修复底板异常。

## 工业海岸：功能关系可以迁移，地区身份不猜

u033 与 u066/u067 的共性是：码头硬地面、货箱按作业区成排、起重机靠水、仓库靠陆地道路；完整工作空地是用途所需，不能为“丰富”塞满家具。公园/市民海沿步道独立于装卸线，工业街不借住户庭院通车。

可选择当前目录确实存在的通用港区对象，如 `GI_Warehouse_01`、`GI_Pier1`、原版货箱与港口吊机，先看对应样例和原生模型，再配置。货箱可形成有逻辑的码垛，但用户对装饰缩放/堆叠未授权时保持默认，不自动大量叠箱；不得缩放民房。船平行停泊位，保留航道；吊臂照模型方向面向货船/装卸区；码头人与车的路线分开。不要把 GI 仓库的存在作为“此图就是直布罗陀/希腊”的证据。

完成每个地块后检查：真实入口、围界开口、餐饮桌与入口、光照服务面、车辆进出、岸壁接缝、岩崖高程、道路连通与地表无假羽化。弱模型可从“住宅前后院”“餐馆小广场”“教堂入口”“港区工作院”四个独立小样板开始，逐块通过画面检查后扩大。
