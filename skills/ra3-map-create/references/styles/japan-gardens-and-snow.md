## 先分三级场景

1. **正式庭园 → 寺院入口**：宽路/石板前场 → 门 → 两侧灯/石景 → 核心建筑。入口是主轴，不能被树或围墙封住。
2. **正式庭园 → 内部池塘/岩景**：由细园路进入一个可以停留的节点；植物集中于边缘、坡脚和石景，水岸留可读边界。
3. **乡村 → 木屋/小院**：短支路到门前硬地，围栏只表示边界；木屋不能贴寺院大广场拼成商业街。
4. **自然野地 → 湖岸/坡地**：宽路走低处或可通行的缓坡；园路环绕小丘，不能直接翻越陡崖。树分前、中、后层，不均匀撒点。
5. **雪季 → 山谷与院落**：高处/背阴积雪、路径裸露、草土低地按案例保留。雪量由用户指定，不把雪季误解为全图同一种白色。

道路对象候选：宽土路 `HawaiiDirtRoad01`，细园路 `YucatanFootpath01`，石边 `MtFujiStoneBorder01/02/03`，人行面 `MtFujiSidewalk01`，台阶 `MtFujiStoneStaircase01`。m068 还使用 IF 街段作部分规则硬路，资产名称不能单独决定场景风格。

先连两个实际目的地，宽路以少转弯为主；细园路才绕池塘和小岩丘。需要上层连接时先做地形坡道，台阶模型只补视觉，不承诺其可通车。转角选同族形状并验证端点，不能每隔一段小折角。

## 一个庭园的执行步骤

1. 选一个核心建筑，确认原比例入口和占地。
2. 画前场，留正门通主路，划定院墙与门洞。
3. 在前场一侧做池塘/岩景，让园路与主入口相连。
4. 放门旁灯、少数石景、墙边灌木，再放背景树。
5. 用不同俯角检查：房屋无重叠，屋檐不撞树，灯照路，岸边模型不悬空。
6. 小范围做地表过渡和边缘处理，保存重开检查锯齿/旧贴图是否变化。当前绘制故障不能用更多石头遮盖后算验收通过。

若一个庭园只剩“树、灯、墙随机散点”，返回第 2 步重做空间。园林的关键是入口、核心、可走路径和停留节点之间的关系。
