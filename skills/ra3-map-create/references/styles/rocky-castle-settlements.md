# 岩岸古堡与石砌聚落

这是独立的补充风格。它与尤卡坦草屋、日本庭园、浮岛科技平台有明显区别，不因为出现在同一挑战合集就混为一个地区。现实国别与确切季节在现有证据中未确认，以“冷凉/较干岩岸古堡”描述，不强定俄国或日本。

## 地表、道路与层高

已观察材料含 `Dirt_Iceland03/04`、`Dirt_Gypsy01/03`、`Grass_Gypsy03/04`、`Pavement_Heidelberg10`、`Pavement_CapeCod01/02` 等。名称跨地区是资产混用，不代表“冰岛泥地只能刷冰岛”。按画面功能选少数材料：岩岸、外土路、内硬场、少量绿带分别有形状。

外部曲线土路沿谷/岸和桥头，内部正式道路与庭院轴线相连。桥口先确定可达宽度，墙在桥口断开，再放两边小服务/灯节点。上层城堡与下层聚落需要真实坡道/阶梯视觉，模型台阶不单独证明游戏可通行。

硬场与自然泥地交界应能读出城墙或路缘边界。自然边不是每格三角齿，边缘细化需要当前编辑器小样验证；旧纹理消失/齿边持续时报告故障，不用围墙或草把全部错误遮住。

## 制作一块可解释的古堡聚落

1. 定外岩岸和主桥头，决定城堡/聚落的高低层。
2. 先主入口和路，再围墙；每个内院至少有一个可到达开口。
3. 石屋沿主轴放，公共教堂/餐馆在节点，原比例不堆叠。
4. 硬前场、生活小院、外侧土路分开，屋旁有少量围界和生活物件。
5. 低植被接岩根/墙脚，高树/裸树在背景，保留建筑视线。
6. 分别看桥头、城墙角、院门、建筑正面、岩崖底部与纹理交界。无法解释的孤立喷泉/椅子/墓园设施先删除，再复制新的街区。
