# 冬季俄国：围合、公共设施与河港

适用于冬季俄国城市、村镇、铁路与河港美化。与 [城市/村镇布局](winter-russia-layouts.md) 一起按需阅读。本页的原版战役样板是俄国村庄 j01、克里姆林宫 j08、海参崴 s03；补充对照官方起义样例 u001、u036、u072。读取的是整个地图的对象与邻接关系，未迁移任务脚本、经济和初始军队。

先实际打开 [哈尔科夫街区近景](../assets/beautification/m053-city-street.jpg)、[冬季公共空间近景](../assets/uprising/u036-detail-props.jpg) 与 [原版模型核对图](../assets/winter-civic/asset-palette.jpg)。前两者学习空间关系，模型核对图用来确认候选外观；图中的存在不保证当前 MOD 有同一资产，仍需查询当前目录。

## 按空间用途选物体

| 空间 | 样例实际使用的候选 | 摆放关系 |
| --- | --- | --- |
| 城市院落、公共建筑 | KR_Fence03、KR_Fence04；KR_Fence01 | 砖墙或铁栏围合，墙角与入口留柱；入口接到人行道，院内保持独立通路。不要每块空地都围墙。 |
| 村镇庭院、后院 | SV_Fence01/02、ST_SovietFence01 | 围菜地、住宅后院或支路边界；门朝进院路径，屋门前留空；住宅前场与后场不同。 |
| 河岸、停车边界、公园边 | KR_ChainBarrier01、OD_ChainBarrier、ST_SovietFence* | 链栏强调边界与出入口，保留走路的开口；港口防护与公园栏杆按外观、实际尺寸分别选。 |
| 街段与公共等待区 | KR_LightPole01、SV_StreetLamp01、SV_Bench01、ST_Trashcan | 灯服务车道或步道；椅子朝活动空间；垃圾桶放在入口、候车或座椅附近，避开通行轴线。 |
| 路口与铁路控制点 | TH_TrafficSignal04、OD_RailSignal01、YP_Gate_Check | 路口设施朝来车方向，铁路信号在轨道边，岗亭在路侧。链栏只表示静态开放边界，不能宣称实现自动落杆。 |
| 市民公共服务 | HospitalTechStructure、GarageTechStructure | 与城市道路相接，配置入口、前场、停车位；原版技术建筑可作为视觉替代，需说明与真实建筑外观的差别。 |
| 纪念广场与绿化 | KR_Statue01、KR_Tree04、KR_TreeGrate01、KR_Shrub* | 雕像形成视线焦点，四周留步道；树坑沿步道，庭院与外围林地用不同密度。不要把纪念碑塞在交通车道上。 |
| 河港 | VL_Dock01、VL_ShippingBoat01、OD_TugBoat01、OD_PortAuthority01、OD_Warehouse* | 岸墙接地、栈桥接岸，客货空间分工；船停靠码头或在航道中，仓库和吊机连接装卸前场，不占公共通道。 |

这些是样例中的共现与功能关系，不是需要全部放置的清单。j08 有 96 个 KR_Fence03、35 个 KR_Fence04，说明砖墙与柱共同组织院落；j01 有 313 个 SV_Fence01，说明村镇的围合语言不同。j08 有医院和车库，s03 有 5 个 VL_Dock01。不要按这些数量缩放复制到新图。

## 接缝、原点与方向

测真实模型后按墙段的局部长轴接端点。KR_Fence03 本次原版几何的直段长约 31.17 世界单位，KR_Fence01 约 23.49；可作为核对起点，不能代替当前 MOD 的测量。墙柱、端段分别查原点，保留真实大门或留出通行口；转角和坡道口须拍近景。不能用缩放墙段或把房屋堆叠来补缝。

街区坐标朝向与模型朝向分开处理。采用 45°、135°、225°、315° 的街区骨架时，模型局部正面仍可能不是 +X。KR_LightPole01 的灯臂朝模型局部 +X：两侧灯需要相反旋转，先做一对灯并看它们是否照向路面。建筑按正门朝街，墙按长轴沿边，不能统一填一个角度。

码头模型原点可能偏离可见中心；VL_Dock01 有明显单侧延伸，先试一个岸—栈桥—船组合再连续布置。对象 z 是相对地面的偏移：船的目标水线应减去海床高度，岸墙和栈桥应分别对齐岸顶、桥面，不能给它们同一个 z 值。

## 材质与验收

铺装地表服从空间用途：广场、院落、医院前场、站台、步道与雪地边界分别组织；铁路道床比周围雪地更窄。构筑边缘用路沿与定向细化，自然林地用局部自动混合。不要对成熟城区整图运行自动边缘处理。

45° 铺装出现等距三角齿时，先在同一机位观察并检查实际混合记录，不能用新增物体遮住问题后宣称修好。自动混合与单边细化不是同一个工具；已知的两侧接缝可用相对方向的单边处理，但须保存、重开、再拍近景验证。绘制数据成功不等于显示正确。

至少检查一个完整街区、一个围墙入口、一对灯、一个路口、一个铁路路口与一个码头的近景。房屋保留原生尺寸并检查真实占地间隔；道路经过公共入口与前场，不穿建筑；不同高程之间提供可通行连接。战役场景按用户任务设计，不自动套遭遇战矿脉、对称基地或初始军队。
