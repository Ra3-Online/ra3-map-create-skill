# 悬崖物件：贴着地貌组织，逐段检查接缝

v5 补充 [74 张起义场景图册](../assets/uprising/gallery.html)，新一轮观察 9,502 个崖物件。[美化规则](uprising-beautification.md) 对照热带海崖、EI 火山/台地、MY 干燥 GRID、HB 城镇草山与 IL 雪岸；[案例数据](uprising-cases.json) 保留角度、Z、探针和邻段局部关系。人工平台和无天然崖岸的城市也保留，不为“完整”强加崖链。

需要台地边界、海崖、坡脚或岩壁时读本页，并打开 [美化图册](../assets/beautification/gallery.html) 的相关案例与 [原点示意](../assets/beautification/cliff-anchor.svg)。先看真实模型，再决定落点与间距。

## 已观察到的风格与规格

本轮通过统一地图服务检查 80 图的 10,981 个悬崖物件，并查询其中 135 种原版模型的真实边界。候选详见 [悬崖目录](cliff-palette.json)，具体位置关系见 [重点案例](beautification-cases.json)。下表是样本采用的组合，不能代替当前游戏/MOD 的资产发现。

| 场景与样本 | 悬崖候选 | 学习位置关系 |
|---|---|---|
| 热带台地 m001 | `YU_CliffWall01..06` 及其他短段；岸边另有 `YU_SeaCliffWall*` | 崖顶沿台地轮廓，转角换规格；坡道口保持可通过；陆崖和海崖分开检查高度 |
| 冬季俄国 m049/m053/m054、雪地 1v1 m005 | `IL_SeaCliffWall01..07`；m049 还用 `VL_CliffWall02` | 雪台地/林缘的高低分界；城市的平台边缘可以接自然崖面，但街道不靠悬崖遮住断口 |
| 日本庭园与台地 m068 | `MJ_CliffWall01..11`，局部也有 YU 段 | 建筑平台外缘、河岸与庭园外圈；墙、石边饰与天然崖面各有用途 |
| 中欧山城 m071 | `HB_CliffWall01..06` | 草地高台边缘与城镇背后的地形阻挡；院落、街道在平台内组织 |
| 地中海 m079 | 该样本使用 `MY_CliffWall02` | 干土丘陵、低台地边缘；城市白墙不能替代天然崖面 |
| 火山岛 m080 | `EI_CliffWall*` 与 `EI_VolcCliffWall01..03` | 普通草地台地和火山裸岩分别选材；火山专用段不是全图通用石壁 |
| 戛纳滨海 m070 | 样本使用 YU 海崖 | 依据实际海岸岩色选材，不能从城市名推出专属悬崖；正规滨海步道另用人工海堤 |

没有自然崖物件的城市样本也有价值：m074/m077 的城岸可通过海堤、道路、墙和地形材质组织。不要为每种风格强行添一圈悬崖。`*_GRID` 与非 GRID 变体的模型大小可能不同，换 ID 后重新查模型，不把它们当同尺寸皮肤。

## 原点、落点与方向

占地几何与可见模型是两回事。例如 `IL_SeaCliffWall01` 的模型局部 Z 约 −147.44..7.69，局部 Y 约 −113.40..−4.51；占地元数据高度为 0。`YU_CliffWall01` 的局部 Z 约 −70.01..7.69；`MJ_CliffWall01` 约向下延伸 60。它们通常以崖顶附近的原点向下铺出岩面，且几何可能偏在原点的一侧。

因此先完成真实台地和坡道，把物件原点落在适合其模型的上沿，保持 `z` 为地面偏移。看低角度画面确认崖脚能进入下层地面，背部不会露在上层通路，顶沿不会高出草地形成一条悬空墙。模型深于实际落差时，下部可以被低地遮住；不要为了让模型底端“落地”而整体抬起模型。若模型规格与落差不适合，换规格或改局部坡面，再调整少量 Z。

`angle` 是度数；世界 Y 向上。模型的局部 +X 不是统一的崖面朝向，最长 AABB 轴也不一定是接缝轴。直段先查模型和两侧高程，在试放一段的俯视、低角度图中确认岩面朝低地。直段已有可靠的局部朝向时，可以用局部前方与目标低地方向的角差求旋转；转角与弧形段须分别确认。

## 相邻段的摆法

沿真实高程边界分成直段、缓转段、尖角、坡道口和收尾。先摆一小段，包括至少一个转角与一个开口；接缝通过后再扩展到整个轮廓。

下列只是实际原点之间的观测，不能当作通用步长：

- m071 的一段 `HB_CliffWall06` 为 225°，相邻 `HB_CliffWall01` 也为 225°，中心间距 100.33；相对前者局部位置约 `(99.83, −10.01)`。它沿上沿前进时也有横向错位。
- m001 的 `YU_CliffWall04` 为 135°，邻接短段 `YU_CliffWall18` 的中心相隔 79.61；另一个 `YU_CliffWall02` 位于局部约 `(−0.57, 99.15)`，朝向变化 −90°，与转角关系相关。
- m053 同一类 `IL_SeaCliffWall01` 的最近中心间距中位数约 70.77，而 m054 的同类约 82.15。不同曲率、不同配对和附近第二条边界都会改变“最近”距离。

对每种模型观察左右接合部、凹凸轮廓和顶部高度。容许少量岩面互相遮住接缝，避免大片相交、穿出柱状背面或重复横纹。短段补小转折，大转角先换转角规格，再改变两邻段落点；不要只让直段绕折线旋转。连续段的顶沿需要跟随同一上层地面，不能因为原点分别采样到不同斜坡高度而一高一低。

打开 [原点与地形诊断](../assets/beautification/cliff-placement.png)：橙箭头为物件局部 +X，蓝虚线仅为最近中心连线。它们不证明接缝连续。哈尔科夫的近景能看到部分接合处条带/柱状凸出；把这些作为复核案例，不能把作者原图中的每段都当成无瑕模板。

## 与地形、纹理和道路配合

台地上沿以区域主材质延续；崖面用同岩色的地形材质补未被模型覆盖的坡面；崖脚用窄而不均匀的碎石、裸土或灌木簇过渡。覆雪场景区分顶面积雪、裸岩、道路清理区，不能给所有岩面刷同一块白色。

坡道是高程与通行性的连接，不是悬崖模型缺口或一条贴图线。先检查实际宽度与坡度，在两肩用收尾段结束崖链；模型、散石、树和围栏都不压住有效宽度。海崖还要检查崖脚与水面、岸边泥沙的关系，不能从陆地镜头判断水线处没有悬空。

放置用 `ra3map_object_geometry` / `ra3map_model_geometry` 查规格，`ra3map_place_object` / `ra3map_batch_place` 写入。读取用 `ra3map_list_objects exact:true`，按实际类型确认邻段；工具缺模型时停止使用该候选，不以未知尺寸强行拼接。

验收看顶沿、低地侧、转角、坡道口和海岸侧的同位置截图，并查通行标志与真正高程。不能仅以“中心间距接近 100”“总物件数够多”或俯视时颜色连贯判定完成。
