# 冬季俄国：哈尔科夫、明斯克和混合港城中的村落

本页加入用户指定的 m053 **哈尔科夫** 和 m054 **明斯克**，与 m049 **俄国村庄任务** 对照。先打开 [冬季案例图册](../assets/beautification/gallery.html#m053) 及三张布局诊断：[哈尔科夫](../assets/beautification/m053-layout.png)、[明斯克](../assets/beautification/m054-layout.png)、[俄国村庄任务](../assets/beautification/m049-layout.png)。

任务原图有军队、经济、触发区和剧本布置；这里只学空间与美化，不能直接照搬为遭遇战资源或阻挡。远景受原图距离雾影响，因此新冬季截图在未保存的临时会话中关闭了雾，并关闭渲染 Bloom；原图没有修改。这是诊断图，保留的光照/色调仍不代表游戏实测。

## 城市街区的组织

哈尔科夫近景显示 VL 系列形成连续街面和围合空间。先画少转折的主路，再由支路定义街坊。长楼沿街调整相同退距，转角处用合适的建筑模型或组合收边，院落留出入口和使用空间。图中类似 L/U 的形状可能来自建筑模型本身；不能仅凭对象中心图就推断为三栋拼接。

街区之间以路、铺装、绿地和地形层次分隔。在高台上让道路与住宅稳定落地，沿外缘结束铺装后接崖顶和低地；不要把房屋底座跨过台地边界。雪覆盖开放地，使用中的车行/院落铺面连续连接到主路；房屋周边的雪、铺装和树群共同解释空间。

在 m053 的近景里可读到路口、沿街灯、围栏开口、院内树和小块绿化。候选包括 `KR_LIGHTPOLE01`、`SV_StreetLamp01`、`KR_FENCE*`、`KR_CHAINBARRIER01`、`KR_Shrub02`、`KR_TREE04`、`SV_AUTO04`；雕像/喷泉用于有空间用途的地标。该图共 177 个 KR 灯柱，不应把这数量按面积比例复制。

明斯克需要分开看主街、开阔住宅片区与村屋组。VL 局部可用城市庭院；较矮的 SV 房屋沿支路成组，保留较大的雪地和林地空隙。道路可以随总体地貌变化，单个房屋仍要有清楚的入口关系；不要让每栋房随机转一个角度。

## 村镇与林缘

以 SV 01/03/04/05/07/08 等候选试做小尺度院落。先确定道路/车辙、房门方向和院落范围，再放一段围栏、工具/木堆、少量树与灌木。围栏可以只围一侧或两侧，院门要连接路；房屋与附属物的间距按真实模型检查。

m049 的山坡村屋周围能见到 `SV_WoodPile01`、`AP_FENCE01`、IL/SV 针叶树、岩石与雪地留白。它们沿林缘、坡脚和生活空间组成不同大小的簇，不平均铺满每栋房的周围。道路旁放必要的灯/标志，远离主街的坡地无需复制城市照明密度。

m054 的一个 VL 院落周围存在 `KR_FENCE01`、KR 灌木、`ST_TABLE02`、`AM_BUSSTOP`、`NY_MAILBOX01` 等跨地域通用物件。它们的存在提供“公交点/座椅/公共入口”等功能线索；不是许可把所有候选塞进每个雪地院落。能否与俄国冬季的模型、尺度、积雪和颜色统一，还需看局部。

## 材质与边界

三图的露出陆地主雪纹 `Snow_Solvang01` 约占 43.87%、56.56%、49.23%。这是描述，不能当作白色覆盖的硬指标。哈尔科夫常见 `Snow_Iceland04` 与 Solvang 雪纹混合；城市铺装用 Vlad/Heidel 等候选。明斯克有更多 Vlad 系列与裸土变化。m049 大量 Sand_Cannes 在海床，不能把它误学为俄国村屋周边主沙面。

把雪面、铺装、脏雪/裸土、树下与岩坡分别组织。道路清理区可保持清晰边界，积雪边用窄而不均匀的混合带；院落入口的材质连续接街道。崖脚的雪、裸岩和碎石跟真实坡脚走，不给每座房刷相同圆环。

## 制作时的最小样板

先做一个城市街坊和一个外围村屋组，分别截图。检查建筑门向、退距、庭院通路、围栏开口、车道宽度和绿化位置，再扩展同主题。不同街坊保留共同路制和材质，但在建筑长度、公共空地、院落边界与植被簇上变化。外围密度、灯和铺装应随用途减少，不能把城区模板缩小后撒到山坡上。

验收时把任务单位隐藏或忽略，单看地形、道路、民房与装饰是否仍有结构；若只有模型多而没有可读街区，返回道路与建筑布局层，不靠增加零碎物件修补。
