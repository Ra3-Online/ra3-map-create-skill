# 80 图中的地形类型与坡道

本轮经统一地图服务重新只读分析全部 80 张图，原图 SHA256 均未变；逐格高程和通行标志计算结构，绘图数据可采样。实际检查全部原预览/布局联系图，对 10 张地域代表图取 3D 总览与局部。并非全部 80 张完成游戏内或逐处 3D 检验。[全量索引](learning-index.json)与[层次比较图](../assets/styles/terrain-levels.svg)用于找样板，不是地形优劣排名。

| 地形类型 | 案例与内部陆地 P10–P90 | 可迁移的关系 |
|---|---|---|
| 主岛、外围山脊与中央层级 | m001 210–284.98；m006 210–280；m008 215.60–281.01 | 高地围出区域，宽口和侧路连接；大平地贴邻强地标，海湾深入岛内。先分区再做细起伏 |
| 工业平台与多层桥接 | m004 / m026 / m030 均 280–350 | 平面层级清晰，连接位置少而明确；平台、台阶与桥可能超出高度图的通行模型，不直接移植为自然岩山 |
| 平坦分岛与海上路线 | m007 / m016 210–210；m017 209.42–210 | 水道、桥口、分岛和登陆点承担空间结构；不能为统计分数加入随机山 |
| 山谷与多层城镇 | m071 210–330；m040 270–552.76；m077 224.98–324.98 | 单个街区所在平面先整平，山脊外留林地；坡道连接街区与高地，城市道路不能凌空跨断层 |
| 自然火山岛 | m080 210–490；m031 210–245.14 | 火山核心作高地标，外围可用平地被山脊/海湾分隔；不要把基地抬成尖锥 |
| 峡谷与强垂直分隔 | m048 210–700；m073 60–200 | 先定义阻挡或可达高地，再规划上下层连接；任务图的绝壁和剧情路线只学地貌 |
| 平城、运河与街区层次 | m058 210–280；m076 250–250；m078 280–280 | 街区、广场、河道、海墙提供层次；保持建造/通行平地并留桥头空间 |
| 庭园、坡地与岸线 | m068 210–330；m079 220–234.28 | 小镇/庭园局部整平，边界转入丘陵与岸坡；不能全图平滑消除外部结构 |

P10–P90 会省略少量峰谷，也不说明一层是否可达；它不是坡道目标高差。结合高度带、成片平地、阻挡和实际图写出区域连接。海床很低而岛上等高时，不能描述为“岛上层次丰富”。任务图的经济、出生点和脚本不照搬到遭遇战。

坡道先确定要连接的两个平面与开口，再画有纵深的过渡，两端留平缓接头。宽度按军队和建筑留白决定：脚本 r=3 的保守检查要完整 7 格宽，但不是游戏官方万能最小宽度。高地边沿用陡壁分隔，坡道区域才渐变；按逐格相邻高差查断坎和侧缘，不用全图平滑修一个接头。

绘制顺序：区域/平面→阻挡边界→坡道/桥/登陆口→基地与矿厂局部整平→海岸/岩壁过渡→细起伏→材质→装饰。主要通路在无装饰阶段检查，装饰后复查。对称设计核对两方高程、可达路径和展开面积；视觉植被变化不能改变通路公平性。
